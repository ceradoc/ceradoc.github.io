Cor

I

Interoperable — AsciiDoc, Markdown, HTML, DOCX translate through one hub, bidirectionally.

Doc

Document — semantically typed models, PARG grammars, faithful round-trips.

02Hub-and-spoke architecture

AsciiDoc⇄ CoreModel⇄ Markdown
◆

Canonical hub

Every format serializes to and from one CoreModel — add a format, get conversions to all others for free.

⇄

Bidirectional

ToCoreModel and FromCoreModel are equally load-bearing: parsing and rebuilding are first-class both ways.

⌘

PARG grammars

Compiled, sealed grammar artifacts drive the parsers — the grammar source is the single source of truth.

03Quick start

# parse AsciiDoc into the CoreModel
$ gem install coridoc-adoc
$ coridoc parse document.adoc --to core

# render the CoreModel to another format
$ gem install coridoc-html coridoc-docx
$ coridoc render document.adoc --to html
Renamed: this project was formerly Coradoc (metanorma/coradoc). It is now Coridoc — Cor (Latin: heart) + I (interoperable) + Doc (document) — living at github.com/coridoc. Legacy coradoc* gems on RubyGems are frozen; use the coridoc* gems above.
