Coridoc

Core document parser suite — bidirectional AsciiDoc & Markdown, one harmonized model.

Gems

GemRoleRelease
coridocCore model — the harmonized document hub
coridoc-adocAsciiDoc front — PARG grammar, format models, bidirectional translation
coridoc-markdownMarkdown front — PARG grammar, format models, bidirectional translation
coridoc-htmlHTML renderer
coridoc-docxDOCX renderer
coridoc-mirrorProseMirror-compatible JSON document model

Quick start

gem install coridoc-adoc
coridoc parse document.adoc --to core
